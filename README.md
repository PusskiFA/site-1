# КРОШКА

Авторский русскоязычный концепт кофейни для портфолио. «Крошка» — вымышленный бренд; меню и часы работы иллюстративные.

Статический HTML/CSS/JavaScript без внешних runtime-зависимостей. Адаптивная страница, категории меню с клавиатурной навигацией, карточки с составом и аллергенами, подбор кофе по двум вопросам, мобильная навигация, смена фото, reduced motion и нативные диалоги.

Сборка: `npm run build`. Проверка синтаксиса: `npm run check`. Для локального просмотра: `python3 -m http.server 8080 --directory dist`.

Фотографии: Unsplash. Manrope: Google Fonts, SIL Open Font License. Полные источники в ASSETS.md.
